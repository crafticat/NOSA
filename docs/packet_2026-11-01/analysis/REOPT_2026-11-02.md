## 2. Method (the original batch sweep, OC "Memory and finding a new optimum" steps 1-4)

1. Per (C, arm) and each integer B from 64 to the 84.0 GB edge: memory first.
   - Ours (allocated basis): mem = line(C) + the INT delta of the same job (0.017-0.018 GB) [+ BF parts for S].
   - FEASIBLE = mem <= 83.15 GB (usable 83.75 minus the 0.6 GB fit margin) for a MODEL configuration. A configuration
     that RAN is feasible by demonstration (inta ran at 83.909 GB). The table also shows the "loose" edge (<= 83.75).
   - The AUTHOR device-used basis is computed separately and never mixed (section 4).
2. Time terms (ms per round).
   - The INT phases at B0 are MEASURED. Away from B0 each phase p scales as the plain arm's phase:
     T_p(B) = rho_p x L_p(B), rho_p = INT_p(B0) / L4PTFD_p(B0) (MEASURED same job). L_p is piecewise linear through the
     plain points (MODEL). Above the last point a local slope applies: C81 = its last segment (192 -> 287); C128 / C73 =
     the chord 64 -> B0 times kappa_p, the C81 ratio (last segment / chord) per phase (draft 1.624, joint 1.251, commit
     1.504; OUT:22). Range: lo = chord (or last segment at C81), hi = central x 1.15. MODEL: the convex shape of C81
     transfers to C128 / C73.
   - T_mean(B) = T_mean(B0) x sum_p T_p(B) / sum_p T_p(B0). Y_c(C) stays fixed in B (MODEL: Y was measured at one B per C).
   - S: T_mean - saving_S; saving_S = wait(B) a - (6.2 + dk r') - jk r'; wait and r' = NEW(C, B) / NEW(anchor) scale
     with B. Calibration reproduces the anchor: +7.38 / +20.42 / -5.67 ms (OUT:24; notes: +7 / +21 / -6).
   - J: T_mean + f FORK(B) + g (FORKT(B) - FORK(B)); central f -2.5 %, g 0.5; best f -15 %, g 1; raw worst f +10 %, g 0;
     adopt-only worst 0 (an ahead level that is slower is not adopted). FORK linear in B (MODEL, as IN:1292).
3. Q_committed = 1000 B Y_c / T_mean (the ratio-of-sums population of the rates; one population). The median basis is
   printed beside it for continuity with LED; it is never mixed with the mean basis.
4. The highest central Q among the feasible B wins; nearby candidates are in OUT:28-95.
